# Aciole Contributions — Purple / Balanced

SVG contribution heatmap generated from the GitHub GraphQL API, using native TypeScript execution on Node.js 24. No npm dependencies, external fonts, tracking, hosting, or third-party image services.

## Contents

- `src/github.ts` — GitHub GraphQL client with timeout and error handling.
- `src/metrics.ts` — date normalization, streaks, totals and other stats.
- `src/render.ts` — accessible purple-themed transparent SVG (desktop + mobile).
- `scripts/generate.ts` — CLI entry point.
- `tests/metrics.test.ts` — deterministic tests.
- `assets/contributions.svg`, `assets/contributions-mobile.svg` — initial placeholder artwork, replaced after first real sync.
- `assets/contributions-demo*.svg` — synthetic previews generated by `npm run preview` (included in the downloadable ZIP).
- `.github/workflows/aciole-contributions.yml` — automated daily generation and commit.
- `README.md` — your original profile README with the old streak replaced by a responsive `<picture>` element.

## Install

Copy the files and directories into your GitHub **profile repository** (`ThiagoAciole/ThiagoAciole`). Keep its main branch as `main`.

1. Commit/push the files to your default branch (or merge the prepared PR).
2. Open **Actions → Update contribution heatmap → Run workflow**.
3. Verify the action committed updated `assets/contributions.svg` and `assets/contributions-mobile.svg`.
4. The README uses a mobile SVG under 720px and the desktop SVG otherwise.

The workflow runs automatically every day at **08:13 UTC**. It needs `GITHUB_TOKEN` provided by Actions and permission `contents: write` to publish the generated SVGs. If your repository uses branch protection, configure a permitted publication mechanism instead of pushing directly to the protected branch.

## Local development

Requires Node.js 22.6+ for `--experimental-strip-types` (Node.js 24 recommended).

```bash
npm test
npm run preview
# View assets/contributions-demo.svg and assets/contributions-demo-mobile.svg

# Real contribution data (do not commit your personal token)
GITHUB_USERNAME=ThiagoAciole GITHUB_TOKEN=your_token npm run generate
```

The preview contains **synthetic contributions**, explicitly marked DEMO. The committed non-demo SVGs are placeholders until the GitHub Action runs successfully. The project never silently falls back to fake data on API failures.

## How the metrics work

- **Contributions**: sum of the daily counts for exactly 365 days, ending today (UTC).
- **Active days**: days with at least one counted contribution.
- **Longest streak**: longest sequence of consecutive active days in the last 365 days.
- **Most active month**: calendar year-month with the highest contribution total inside the window; partial months count only observed days.
- **Most active weekday**: weekday with the largest total number of contributions (not necessarily the most distinct active days).
- **Active day rate**: active days divided by 365, rounded to the nearest integer.

GitHub counts contributions according to its own contribution rules. Access through the Actions `GITHUB_TOKEN` generally reports publicly visible contributions; restricted contributions may require separate credentials and may not appear identically to the owner's authenticated profile.

## Themes and responsiveness

The SVG has **no full-size opaque background**. Metric cards are slightly translucent, with rounded corners. CSS `prefers-color-scheme` changes text and inactive cells for light themes. It uses a fixed SVG viewBox, which scales to any container, and includes a second mobile layout selected by `<picture>`.

The theme is configured in `src/render.ts` through the `COLORS` array and the SVG style rules.
